## 3. 편집기 화면 (작업 영역)

프리미어 · 애프터 이펙트처럼 칸으로 나뉜 작업 영역이에요. 기본 비율은 왼쪽 30% · 미리보기 43% · 장면 편집 27%예요.

```
┌ 영상 보관함 · 점수 변수 ┬ 미리보기 ┬ 장면 편집 ┐
│                       │          │           │
├───────────────────────┴──────────┤ (전체 높이) │
│ 장면 지도 (넓은 칸)                │           │
└──────────────────────────────────┴───────────┘
  ① 장면 6개  ② 영상 0/6 연결  ③ 선택지 모두 연결됨  ④ 내보내기   ← 하단 진행 상태
```

| 기능 | 사용법 |
|---|---|
| **패널 자리 바꾸기** | 패널 탭(⠿)을 끌어서 다른 칸 **가운데**에 놓기 |
| **탭으로 합치기** | 패널 탭을 다른 칸의 **탭 줄** 위에 놓기 |
| **빈 칸 자동 접기** | 칸이 비면 접히고 옆 칸이 그 자리까지 넓어짐. 탭을 끄는 동안에는 빈 칸이 다시 나타나서 그곳에 놓을 수 있음 |
| **칸 크기 조절** | 칸 사이 경계선 끌기 (더블클릭: 원래대로) |
| **작업 영역 높이** | 아래 "끌어서 작업 영역 높이 조절" 손잡이 끌기, 페이지를 스크롤해서 넓게 사용 |
| **큰 창으로 보기** | 탭 오른쪽 **⤢** → 화면 위에 뜨는 큰 창 (✕ · Esc · 바깥 클릭으로 닫기) |
| **배치 프리셋** | 상단 **작업 영역 ▾** → 기본 편집 / 장면 연결 집중 / 미리보기 집중 / 높이 프리셋 |
| **진행 상태** | 하단 막대에 장면 수, 영상 연결 수, 연결 안 된 선택지 수 표시 |
| **화면 테마** | 상단 **◐ 자동 / ☀ 라이트 / ☾ 다크** 버튼으로 전환 (자동은 시스템 설정을 따름, 영상이 나오는 미리보기 화면은 항상 어둡게) |

배치, 높이, 테마는 브라우저에 기억돼요. 상단 바는 스크롤해도 고정됩니다.

## 4. 장면 지도

피그마처럼 장면 박스를 끌어서 연결하고 배치하는 노드 편집기예요.

```
┌ 시작 ─────────────────┐
○ 퇴근길 골목              │  ← 위쪽(머리)을 끌면 박스 이동
│ 글자 화면                │
├──────────────────────┤
│ 1 소리를 따라간다  조건 ●──→ 다른 장면으로 이어짐
│ 2 모른 척 집으로 간다    ●──→
│ ＋ 끌어서 새 갈래        ◌   ← 끌면 선택지 추가 + 연결
└──────────────────────┘
```

| 하고 싶은 것 | 방법 |
|---|---|
| 선택지를 장면에 연결 | 선택지 오른쪽 **● 점을 끌어서** 장면 박스에 놓기 (놓을 곳이 파랗게 빛남) |
| 새 갈래 만들기 | **＋ 끌어서 새 갈래** 점을 장면에 놓기 |
| 새 장면까지 한 번에 | 점을 **빈 곳에 놓기** → 그 자리에 새 장면 생성 + 연결 |
| 장면 옮기기 | 박스 위쪽 끌기 (8px 격자) 또는 방향키 |
| 연결 끊기 / 선택지 삭제 | **선 클릭** → 연결 끊기 · 선택지 삭제 버튼, 또는 Delete |
| 선택지 편집으로 이동 | 박스 안 **선택지 줄 클릭** → 오른쪽 편집 칸의 해당 선택지로 이동 |
| 화면 이동 / 확대 | 빈 곳 끌기 / **Ctrl+휠** · − + 버튼 / Shift+휠 옆으로 |
| 정리 | **전체 보기**, **자동 정렬** (흐름 순서대로 재배치) |
| 되돌리기 | **↶ ↷** 버튼 또는 Ctrl+Z / Ctrl+Shift+Z |

| 표시 | 의미 |
|---|---|
| 빨간 점 | 아직 연결 안 된 선택지 |
| `⏱ 시간 초과 시` 줄 · 빨간 점선 | 제한 시간 안에 못 골랐을 때 가는 길. 점을 끌어서 장면에 연결, 빈 곳에 놓으면 **실패 엔딩**이 자동으로 생김 |
| `조건` · `점수` 배지 | 조건이 있는 선택지 · 점수가 바뀌는 선택지 |
| 점선 연결선 | 조건이 있는 길 |
| 점선 테두리 박스 | 점수에 따라 자동 이동하는 장면 |
| `시작` · `END` | 시작 장면 · 엔딩 장면 |

## 5. 장면 편집

장면 하나를 단계별로 설정해요.

| 단계 | 내용 |
|---|---|
| **① 무엇을 보여줄까요?** | 영상 파일을 **끌어다 놓기**, 보관함에서 고르기, 또는 **글자 화면**(영상 없이 문장 + 배경색 + 길이) |
| **② 영상이 끝나면** | **선택지 보여주기** / **점수에 따라 자동 이동** / **여기서 끝(엔딩)** |
| **③ 선택지** | 버튼 글자 + "누르면 →" 이동할 장면, 조건 · 점수 (선택 사항), 버튼 모양 (글자 버튼 / 🎯 투명 클릭 영역) |
| **고급 설정** | 선택지 나오는 시점, 제한 시간, 시간 초과 시 자동 선택, 남은 시간 막대 숨기기, 고르는 동안 반복 |
| **이 장면에 들어올 때 점수 바꾸기** | 장면 시작과 동시에 점수 변경 |

### 영상이 끝나면 (장면 종류 4가지)

| 종류 | 설명 |
|---|---|
| 선택지 보여주기 | 플레이어가 버튼이나 클릭 영역으로 다음 장면을 골라요 |
| 점수에 따라 자동 이동 | 위 규칙부터 확인해서 조건이 맞는 장면으로 이동 |
| **바로 다음 장면** | 고르는 화면 없이 연결된 장면으로 이어서 재생 (보상 장면 · 연결 장면) |
| **여기서 끝** | 🏁 **엔딩**(THE END) 또는 💀 **게임 오버**(붉은 GAME OVER) 중 고르고, 장면 이름 아래 나올 **문구**를 적어요 |

게임 오버에서 **이전 선택으로**를 누르면 실패 직전 선택으로 돌아가요. 점수와 가방도 그때 상태로 돌아가요.

게임 오버 화면 아래 **이 지점으로 돌아가기**에는 지나온 장면이 최근 순으로 나와요. 물건을 안 받고 지나쳐서 실패했을 때, 여러 번 누를 필요 없이 그 장면을 눌러 바로 돌아가요.

### 가만히 있어야 통과하는 장면

선택지를 하나도 두지 않고 **제한 시간** + **시간 안에 못 고르면 › 다른 장면으로 이동**(다음 장면)을 정하면, 끝까지 아무것도 누르지 않아야 통과해요. **화면 클릭 설정 › 영역 밖을 누르면**에 실패 장면을 고르면 화면을 누르는 순간 실패해요.

### 시간 초과 → 실패 엔딩 만들기

| 방법 | 순서 |
|---|---|
| 편집 칸에서 | 고급 설정 › **제한 시간**을 정함 → **시간 안에 못 고르면** › **다른 장면으로 이동** → 장면 고르기 또는 **＋ 실패 엔딩 새로 만들기** |
| 장면 지도에서 | 제한 시간이 있는 장면의 **⏱ 시간 초과 시** 줄 점을 끌어서 엔딩 장면에 놓기 (빈 곳에 놓으면 실패 엔딩 자동 생성) |

플레이 중 시간이 다 되면 선택지가 흐려지고 바로 그 장면으로 넘어가요. 되돌리기 기록에는 "시간 초과"로 남아요.

### 선택지 나오는 시점 조절

고급 설정의 타임라인에서 **주황 손잡이를 좌우로 끌면** 선택지가 나오는 시점이 바뀌어요.

| 조작 | 결과 |
|---|---|
| 손잡이 끌기 | 0.1초 단위로 시점 변경 (위에 시간 표시) |
| 맨 끝으로 끌기 · 더블클릭 | "영상이 끝날 때" 선택지 표시 |
| 손잡이 선택 후 ← → | 0.1초씩 (Shift: 1초씩) |

### 인터랙티브 비디오 동작

| 기능 | 설명 |
|---|---|
| 제한 시간 | 선택지가 나온 뒤 정한 시간 안에 골라야 함 (스킨에 줄어드는 막대 / 원형 카운트다운) |
| **시간 안에 못 고르면** | ① 정해 둔 선택지를 자동으로 고르기, 또는 ② **다른 장면으로 이동** (실패 엔딩 · 게임 오버 등) |
| 대기 중 반복 | 고르는 동안 선택지가 나온 지점부터 끝까지 반복 재생 (끄면 마지막 화면에서 정지) |
| 되돌리기 | 플레이 중 "이전 선택으로"를 누르면 점수까지 그 시점으로 복원 |
| 크로스페이드 | 장면이 바뀔 때 부드럽게 전환 |

## 6. 선택지 화면 위치 · 투명 클릭 영역

장면 편집 › 선택지 아래 **화면에서 선택지 위치**에서 장면마다 정할 수 있어요.

| 선택 | 결과 |
|---|---|
| 기본 | 선택지 모양(스킨)의 원래 위치 |
| 아래 · 위 · 가운데 · 왼쪽 · 오른쪽 | 그 위치에 선택지 묶음 표시 |
| **직접 배치** | 미리보기가 선택지 직전 화면에서 멈추고, **버튼 하나하나를 끌어다 놓기** |

직접 배치에서는 가운데 근처로 가면 **안내선이 뜨면서 딱 맞춰지고**, 가로 · 세로 정렬 버튼도 있어요. 화면 끝에 놓아도 버튼이 잘리지 않도록 가장자리에 맞춰져요. 정한 위치는 내보낸 게임에도 그대로 적용됩니다.

선택지 모양(스킨)은 두 가지예요.

| 스킨 | 모양 |
|---|---|
| **시네마** | 영화 자막처럼 아래에 명조체 선택지, 가운데에서 줄어드는 제한 시간 막대 |
| **카드** | 오른쪽에 번호가 붙은 카드형 버튼, 원형 카운트다운 |

### 🎯 투명 클릭 영역 (핫스팟)

버튼 대신 **영상 속 물체를 직접 누르게** 하는 보이지 않는 선택지예요. 이상현상 찾기, 단서 클릭, 숨은 물건 찾기에 써요.

| 순서 | 방법 |
|---|---|
| ① | 선택지 카드에서 **🎯 투명 클릭 영역**을 누름 → 미리보기가 선택지 직전 화면에서 멈춤 |
| ② | 노란 상자를 **끌어서 이상현상 위로**, 오른쪽 아래 **모서리로 크기** 맞추기 → **완료** |
| ③ | 제한 시간을 정하고 **시간 안에 못 고르면 › 다른 장면으로 이동** (이상현상에 당하는 엔딩) |
| ④ | (선택) **영역 밖(빈 곳)을 누르면** › 실패 장면 고르기 → 아무 데나 마구 누르기 방지 |

| 설정 | 설명 |
|---|---|
| 영역 밖을 누르면 | 아무 일도 없음 / 고른 장면으로 이동 (빨간 ✕ 표시 후 이동) |
| 플레이어에서 테두리 살짝 보이기 | 튜토리얼 장면용. 끄면 완전히 투명 |
| 남은 시간 막대 숨기기 | 시간은 흐르지만 막대가 안 보여 긴장감 ↑ (고급 설정) |
| 미리보기 › **클릭 영역 보기** | 편집할 때만 영역을 노랗게 표시 (내보낸 게임에는 안 보임) |

- 마우스 커서가 영역 위에서 바뀌지 않아서 위치가 들통나지 않아요 (화면 전체가 조준선 커서).
- 정답 영역을 누르면 하얀 파동, 헛클릭은 빨간 ✕가 잠깐 나와요.
- 숫자키 1–9로는 고를 수 없어요 (글자 버튼만 숫자키로 선택).
- 글자 버튼과 섞어 쓸 수 있어요. 예: 이상현상 영역 + "그냥 지나간다" 버튼.

## 7. 점수 변수

플레이어가 고른 것을 **기억해 두는 값**이에요. 점수 변수 패널의 **점수 변수란?** 을 누르면 사용법과 예시를 크게 볼 수 있어요.

| 종류 | 예 | 바꾸기 | 조건 |
|---|---|---|---|
| **숫자 점수** | 호감, 용기, 실수 | 더하기 · 빼기 · 로 바꾸기 | 이상 · 이하 · 같음 · 아님 · 초과 · 미만 |
| **스위치** | 열쇠, 비밀을_알았다 | 켜기 · 끄기 | 켜져 있을 때 · 꺼져 있을 때 |

| 기능 | 설명 |
|---|---|
| 고르기 상자로 설정 | `[호감] [3] [이상]`, `[열쇠] [켜기]`처럼 직접 입력 없이 선택 |
| 조건 선택지 | **이럴 때만 이 선택지 보이기** |
| 점수 변경 | **고르면 점수 바꾸기**, **이 장면에 들어올 때 점수 바꾸기** |
| 자동 분기 | 장면을 **점수에 따라 자동 이동**으로 바꾸면 위 규칙부터 조건이 맞는 장면으로 바로 이동 (조건 없는 규칙 = 그 밖의 경우) |
| 예시로 바로 추가 | 호감 · 용기 · 돈 · 실수 · 열쇠 · 비밀을_알았다 |
| 이름 바꾸기 | 이름을 바꾸면 쓰인 곳도 자동으로 함께 수정, 삭제하면 쓰인 조건도 정리 |
| 게임 화면에 표시 | 켜면 플레이 중 화면 오른쪽 위에 값 표시 (값이 바뀌면 살짝 튀는 효과) |
| 실시간 값 | 플레이 중 각 변수 옆과 미리보기 아래에 지금 값 표시 |

### 활용 예시

| 예시 | 만드는 법 |
|---|---|
| 호감도에 따라 엔딩 나누기 | 친절한 선택지마다 `호감 1 더하기` → 마지막 장면을 자동 이동으로, `호감 3 이상 → 해피엔딩`, 조건 없음 `→ 노멀엔딩` |
| 아이템이 있어야 열리는 선택지 | "열쇠를 줍는다"에 `열쇠 켜기` → "문을 연다"는 `열쇠 켜져 있을 때`만 보이게 |
| 한 번 본 장면 기억하기 | 회상 장면에 들어올 때 `비밀을_알았다 켜기` → 다른 장면 선택지 조건으로 사용 |
| 실수가 쌓이면 게임 오버 | 틀린 선택지마다 `실수 1 더하기` → 자동 이동으로 `실수 3 이상 → 게임 오버` |

### 🎒 가방 표시

점수 변수 패널의 **게임 화면 표시**를 **🎒 가방**으로 바꾸면, 켜진 스위치만 화면 오른쪽 위 가방에 물건처럼 들어가요.

| 설정 | 설명 |
|---|---|
| 가방 이름 | 기본 "🎒 가방", 원하는 이름으로 변경 |
| 아이콘 | 스위치마다 그림 문자 (🔦 🔔 🎫 등) |
| 가방에 표시 | 체크한 스위치만 가방에 들어감 |

물건을 얻으면 튀어나오듯 들어오면서 "🔦 손전등을 얻었다" 알림이 잠깐 뜨고, 잃으면(스위치 끄기) "…을 내려놓았다" 알림과 함께 사라져요. 되돌리기로 돌아갈 때는 알림이 뜨지 않아요. 숫자 점수는 가방 옆에 따로 표시돼요.

### 시작 화면 · 크레딧

파일 › **시작 화면 · 크레딧** (또는 미리보기 시작 화면의 ✎ 버튼)에서 고쳐요. 내보낸 게임에도 그대로 나와요.

시작 버튼을 한 번 누르고 재생이 시작되므로, 브라우저가 소리 자동 재생을 막는 문제도 피할 수 있어요.

### 프로젝트 저장

상단 **파일 ▾** 메뉴나 단축키로 여러 프로젝트를 이름 붙여 저장하고 다시 열 수 있어요.

| 기능 | 단축키 | 설명 |
|---|---|---|
| **저장** | `Ctrl+S` | 지금 프로젝트를 이름 그대로 저장 (처음이면 새로 저장) |
| **다른 이름으로 저장** | `Ctrl+Shift+S` | 새 이름으로 따로 저장, 원본은 그대로 |
| **열기** | `Ctrl+O` | 저장해 둔 프로젝트 목록에서 골라 열기 (삭제도 가능) |
| 저장 상태 | | 프로젝트 이름 아래에 `저장됨 · 오늘 15:20` / `● 저장 안 된 변경` 표시, 눌러서 바로 저장 |
| 자동 보관 | | 저장과 별개로 작업 중인 내용은 계속 자동 보관돼서 새로고침해도 이어서 작업 가능 |

저장 안 된 변경이 있을 때 다른 프로젝트를 열려고 하면 한 번 더 확인해요. 시작 화면에서도 **저장한 프로젝트 열기**를 고를 수 있어요.

### 영상 보관함

| 기능 | 설명 |
|---|---|
| 영상 보관함 | 넣은 영상은 브라우저에 저장돼서 **새로고침해도 유지** |
| 재사용 | 여러 장면에서 같은 영상을 "보관함에서 고르기"로 사용 |
| 미리보기 썸네일 | 영상마다 작은 미리보기 그림과 사용 중인 장면 표시 |
| **이 장면에 넣기** | 지금 고른 장면에 그 영상을 바로 연결 (미리보기도 즉시 바뀜) |
| **선택 모드** | 평소에는 영상 추가만 보이고, 오른쪽 위 **선택**을 누르면 체크박스와 도구(모두 선택 · 안 쓰는 영상 고르기 · 이름 바꾸기 · 선택한 영상 삭제)가 나타남. **완료**로 돌아감 |
| **이름 바꾸기** | 선택 모드에서 하나를 고르고 이름 바꾸기 → Enter. 확장자 유지, 그 영상을 쓰는 장면도 함께 바뀜 (같은 이름은 거부) |
| **골라서 삭제** | 선택 모드에서 줄을 눌러 여러 개 고르고 → 선택한 영상 삭제 |

> 보관함은 **그 브라우저에만** 있어요. 다른 PC에서 이어서 작업하려면 zip으로 내보낸 뒤 불러오세요.

## 11. 내보내기 · 불러오기

**내보내기**를 누르면 플레이어와 영상이 한 폴더에 담긴 zip이 저장돼요.

```
프로젝트이름/
├─ index.html      ← 더블클릭하면 게임 실행 (편집기 없이 플레이어만)
├─ project.json    ← 편집기로 다시 불러올 때
├─ README.txt
└─ videos/         ← 장면에 쓴 영상
```

| 기능 | 설명 |
|---|---|
| 저장 전 점검 | 연결 안 된 선택지, 보관함에 없는 영상, 시작에서 갈 수 없는 장면을 미리 알려 줌 |

| JSON 보기 | 파일 → 프로젝트 JSON 보기 (복사 · 붙여넣어 적용) |

## 12. 단축키

입력칸에 글자를 쓰는 중이 아닐 때 동작해요. 장면 지도 관련 키는 지도의 빈 곳을 한 번 클릭한 뒤 쓰세요. 장면 지도의 **단축키** 버튼으로도 볼 수 있어요.

| 키 | 동작 |
|---|---|
| `Ctrl+S` · `Ctrl+Shift+S` · `Ctrl+O` | 저장 · 다른 이름으로 저장 · 열기 |
| `Ctrl+Z` | 되돌리기 (편집 전체) |
| `Ctrl+Shift+Z` · `Ctrl+Y` | 다시 실행 |
| `Delete` | 선택한 선택지(줄 · 연결선) 또는 장면 삭제 |
| `Ctrl+D` | 장면 복제 (선택지 연결까지) |
| `Ctrl+C` · `Ctrl+V` | 장면 복사 · 붙여넣기 |
| `방향키` (`Shift`) | 선택한 장면 옮기기 (8px / 40px) |
| `Ctrl+휠` · `Ctrl` + `−` `=` · `Ctrl+0` | 장면 지도 확대 · 축소 · 100% (브라우저 화면 확대는 막음) |
| `F` · `N` · `Esc` | 전체 보기 · 새 장면 · 선택 해제 / 창 닫기 |
| `1`–`9` · `Space` · `B` | 미리보기에서 선택 · 일시정지 · 이전 선택 |

## 13. 구조 (개발자용)

하나의 `index.html` 안에 엔진과 편집기가 분리되어 있어요. 내보낼 때는 엔진 부분만 플레이어로 복사됩니다.

| 항목 | 사용 기술 |
|---|---|
| 언어 | HTML · CSS · JavaScript (프레임워크 없이 단일 파일) |
| 저장 | IndexedDB (영상 Blob · 프로젝트), localStorage (화면 배치 · 테마) |
| 내보내기 | JSZip (cdnjs) |
| 배포 | GitHub Pages |

```
index.html            편집기 (엔진 + 편집기)
prototypes/<이름>/    플레이 가능한 프로토타입 5종 (내보내기 결과와 같은 구조)
README.md
```

| 계층 | 위치 | 역할 |
|---|---|---|
| **엔진 코어** | `<script id="engine-src">` 의 `IVEngine` | 재생, 선택 타이밍, 제한 시간, 반복, 점수 변수, 자동 이동, 되돌리기(`back`, 여러 단계 `rewind(n)`). UI를 모르고 이벤트만 발행 |
| **미디어 어댑터** | `VideoAdapter` · `PlaceholderAdapter` · `Media.resolve` | 실제 영상 / 글자 화면을 같은 인터페이스로 재생. `resolve`만 바꾸면 영상 출처 교체 |
| **스킨** | `Skins.register({id, name, mount})` | 영상 위 선택지 UI. 위치 프리셋과 직접 배치 지원 |
| **점수 표시** | `VarHud` | 플레이 화면에 변수 값 표시 (점수 목록 / 가방 모드) |
| **시작 화면 · 엔딩** | `Intro` · `fillEnd` | 시작 화면, 크레딧, 엔딩 / 게임 오버 화면 |
| **클릭 영역** | `HotLayer` | 스킨과 별개로 영상 위에 투명 버튼을 깔고, 헛클릭을 `engine.miss()`로 전달 |
| **조건 언어** | `Logic` | `호감>=3 && 열쇠==1`, `호감+=1, 열쇠=1` 형식을 eval 없이 해석 |
| **저장소** | `Store` (IndexedDB) | 영상 Blob과 프로젝트 저장. 같은 메서드로 Supabase · Drive 어댑터 교체 가능 |
| **편집기** | 두 번째 `<script>` | 작업 영역, 장면 지도, 장면 편집, 점수 변수, 보관함, 템플릿, 되돌리기, 내보내기 |
| **플레이어 CSS** | `<style id="player-css">` | 내보낸 플레이어에 그대로 복사되는 스타일 |

### 엔진 이벤트

| 이벤트 | 데이터 | 시점 |
|---|---|---|
| `scene` | `{scene, vars}` | 장면 시작 |
| `time` | `{t, d, scene, phase}` | 매 프레임 |
| `choices` | `{list, timeLimit, defaultId, scene}` | 선택지 등장 |
| `timer` | `{remain, total}` | 제한 시간 카운트다운 |
| `chosen` | `{choice, timeout, miss}` | 선택 확정 (시간 초과 · 헛클릭 포함) |
| `end` | `{scene, vars, path}` | 엔딩 도달 |
| `state` | `{paused, muted}` | 재생 상태 변경 |

### 장면 데이터

프로젝트에는 `intro {sub, note, credits}`, `hud {mode:'list'|'bag', title}`, `varMeta[이름].icon`도 있어요.

```js
{
  id, title,
  media: { type: 'file' | 'placeholder', name, duration, caption, color },
  choiceAt,          // 선택지 나오는 시점(초), '' = 영상 끝
  timeLimit,         // 제한 시간(초), 0 = 무제한
  defaultChoice,     // 시간 초과 시 자동 선택
  timeoutMode,       // 'scene'이면 시간 초과 시 timeoutTarget 장면으로 이동
  timeoutTarget,     // 시간 초과 시 갈 장면 (실패 엔딩 등)
  hideTimer,         // 남은 시간 막대 숨기기
  missTarget,        // 투명 영역 밖을 눌렀을 때 갈 장면
  hotHint,           // 플레이어에서 투명 영역 테두리 살짝 표시
  loop,              // 고르는 동안 반복
  ending, auto,      // 엔딩 / 점수에 따라 자동 이동
  next,              // 바로 다음 장면 (auto와 함께 true, choices[0].target으로 이동)
  endKind, endText,  // 'over'면 게임 오버 화면 / 엔딩 화면 문구
  enter,             // 장면에 들어올 때 점수 변경
  cpos,              // 선택지 화면 위치 ('', bottom, top, center, left, right, free)
  pos,               // 장면 지도 위치
  choices: [{ id, label, target, if, set, spot, hot }]   // hot=true면 투명 영역, spot{x,y,w,h} (화면 %, x·y는 가운데)
}
```
