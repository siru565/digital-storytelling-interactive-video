# 디지털스토리텔링 인터랙티브 비디오 제작용

웹 기반 **인터랙티브 비디오(분기형 영상 게임) 엔진** 프로토타입입니다. 디지털스토리텔링 과목 과제로 제작했습니다.

🔗 **[웹에서 바로 열기](https://siru565.github.io/digital-storytelling-interactive-video/)**

영상을 넣고, 선택지로 장면을 이어서, 플레이어와 영상을 폴더째 내보낼 수 있습니다.

## 바로 실행하기

**▶ [https://siru565.github.io/digital-storytelling-interactive-video/](https://siru565.github.io/digital-storytelling-interactive-video/)**

설치 없이 위 링크를 열면 편집기가 실행됩니다 (Chrome·Edge 권장).
만든 영상과 프로젝트는 각자 브라우저에 저장되므로, 팀원과 주고받을 때는 **내보내기(zip) → 불러오기**를 사용하세요.

로컬에서 실행하려면 저장소를 내려받아 `index.html`을 브라우저로 열면 됩니다.

## 프로토타입 바로 플레이

편집기의 **새로 만들기** 화면에 템플릿으로도 들어 있어요. 모두 영상 대신 글자 화면으로 되어 있어서, 흐름을 확인한 뒤 장면마다 영상만 넣으면 됩니다.

| 프로토타입 | 보여 주는 기능 | 플레이 |
|---|---|---|
| 자정의 골목길 | 기본 분기, 제한 시간, 조건 선택지, 엔딩 3개 | [▶ 플레이](https://siru565.github.io/digital-storytelling-interactive-video/prototypes/midnight-alley/) |
| 첫 만남 · 호감도 엔딩 | 점수 변수, 점수에 따라 자동 이동 | [▶ 플레이](https://siru565.github.io/digital-storytelling-interactive-video/prototypes/first-meeting/) |
| 열쇠와 문 · 방 탈출 | 켬/끔 스위치, 아이템이 있어야 보이는 선택지 | [▶ 플레이](https://siru565.github.io/digital-storytelling-interactive-video/prototypes/escape-room/) |
| 추격전 · 시간 제한 선택 | 짧은 제한 시간, 실수 카운트, 자동 이동 | [▶ 플레이](https://siru565.github.io/digital-storytelling-interactive-video/prototypes/chase/) |

각 폴더(`prototypes/…`)에는 내보내기 결과와 같은 구조로 `index.html`, `project.json`, `README.txt`가 있어요.

## 편집기 화면

프리미어·애프터 이펙트처럼 칸으로 나뉜 작업 영역이에요.

| 칸 | 기본 패널 |
|---|---|
| 위 왼쪽 | 영상 보관함 · 점수 변수 |
| 위 가운데 | 미리보기 |
| 아래 (두 칸 너비) | 장면 지도 (노드를 끌어서 연결·이동) |
| 오른쪽 (전체 높이) | 장면 편집 |

- 패널 탭(⠿)을 다른 칸 **가운데에 놓으면 자리 바꾸기**, 다른 칸의 **탭 줄에 놓으면 탭으로 합치기**
- 칸 사이 경계선을 끌어서 크기 조절, 작업 영역 아래 손잡이로 전체 높이 조절
- 상단 **작업 영역** 메뉴에 기본 편집 / 장면 연결 집중 / 미리보기 집중 배치

## 선택지 화면 위치

장면 편집 › 선택지 아래 **화면에서 선택지 위치**에서 고를 수 있어요.

| 선택 | 결과 |
|---|---|
| 기본 | 선택지 모양(스킨)의 원래 위치 |
| 아래 · 위 · 가운데 · 왼쪽 · 오른쪽 | 그 위치에 선택지 묶음 표시 |
| 직접 배치 | 미리보기 화면 위에서 버튼 하나하나를 끌어다 놓기 (가운데 맞춤 안내선, 가로·세로 정렬) |

## 큰 창으로 보기

- 각 칸 오른쪽 위 **⤢** 버튼: 그 칸을 화면 위에 뜨는 큰 창으로 띄우기 (Esc·바깥 클릭·✕로 닫기)
- 상단 **⛶ 큰 화면 미리보기**: 선택한 장면부터 큰 창에서 바로 플레이

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl+Z / Ctrl+Shift+Z · Ctrl+Y | 되돌리기 / 다시 실행 (편집 전체) |
| Delete | 장면 지도에서 선택한 선택지(줄·연결선) 또는 장면 삭제 |
| Ctrl+D · Ctrl+C / Ctrl+V | 장면 복제 · 복사 / 붙여넣기 |
| 방향키 (Shift) | 선택한 장면 옮기기 |
| Ctrl+휠 · Ctrl + / − · Ctrl+0 | 장면 지도 확대·축소 (브라우저 화면 확대는 막음) |
| F · N · Esc | 전체 보기 · 새 장면 · 선택 해제 |

## 점수 변수

| 종류 | 예 | 쓰는 곳 |
|---|---|---|
| 숫자 점수 | 호감, 용기, 실수 | 고르면 더하기·빼기·바꾸기, "3 이상일 때" 같은 조건 |
| 켬/끔 스위치 | 열쇠, 비밀을_알았다 | 고르면 켜기·끄기, "켜져 있을 때" 조건 |

- 선택지마다 **이럴 때만 보이기**(조건)와 **고르면 점수 바꾸기**를 고르기 상자로 설정
- 장면을 **점수에 따라 자동 이동**으로 바꾸면, 위 규칙부터 조건이 맞는 장면으로 바로 이동
- **이 장면에 들어올 때 점수 바꾸기**로 장면 진입 시 자동 적용
- **게임 화면에 표시**를 켜면 플레이 중 화면 오른쪽 위에 값이 보임

## 구조

| 계층 | 위치 | 역할 |
|---|---|---|
| 엔진 코어 | `<script id="engine-src">` 의 `IVEngine` | 재생, 선택 타이밍, 제한 시간, 반복, 점수 변수, 되돌리기. UI를 모르고 이벤트만 발행 |
| 미디어 어댑터 | `VideoAdapter`, `PlaceholderAdapter`, `Media.resolve` | 실제 영상 / 글자 화면을 같은 인터페이스로 재생. `resolve`만 바꾸면 영상 출처 교체 |
| 스킨 | `Skins.register({id, name, mount})` | 영상 위 선택지 UI. 시네마형, 카드형 기본 제공 |
| 저장소 | `Store` (IndexedDB) | 영상 Blob과 프로젝트 JSON 저장. 같은 메서드로 다른 저장소 어댑터 교체 가능 |
| 편집기 | 두 번째 `<script>` | 패널 작업 영역, 노드형 장면 지도, 장면 편집, 점수 변수, 영상 보관함, 템플릿, 내보내기/불러오기 |
| 점수 표시 | `VarHud` | 플레이 화면에 선택한 변수 값 표시 |
